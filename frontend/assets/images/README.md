# GatherSpace — brand asset kit (Neon Night)

Every image in this folder is generated by `generate_assets.py` (Pillow +
the Unbounded/Manrope fonts from `node_modules/@expo-google-fonts`).
Regenerate after changing the brand:

```bash
cd frontend/assets/images
python generate_assets.py
```

## Shipped with the app (referenced from `app.json`)

| File | Size | Purpose |
|---|---|---|
| `icon.png` | 1024×1024 | Launcher / store icon (no transparency — required by the App Store) |
| `adaptive-icon.png` | 1024×1024 | Android adaptive icon foreground; background colour `#0D0B1A` is set in `app.json` |
| `splash-image.png` | 1024×1024 | Splash mark + wordmark (transparent); splash background `#0D0B1A` is set in `app.json` |
| `favicon.png` | 256×256 | Web favicon |
| `notification-icon.png` | 256×256 | White silhouette for the Android status bar |

Icon and splash changes only appear after a new native build
(`eas build`), not through Metro or an OTA update.

## Store listing

| File | Where |
|---|---|
| `icon.png` | Play Console → Store listing → App icon (upload resizes to 512×512) |
| `feature-graphic.png` (1024×500) | Play Console → Store listing → Feature graphic |
| Phone screenshots | Capture 2–8 at 1080×1920 or larger from a production build |
